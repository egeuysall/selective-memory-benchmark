04 / tradeoff

Lower proxy cost does not imply lower wall time.

This plot is descriptive for one replay. The x-axis is an estimated total token-cost proxy, not USD; the y-axis is observed end-to-end wall time. Lower-left is cheaper and faster, but accuracy is labeled independently.

Metric-specific conclusion. Selective memory has the highest audited accuracy and uses 18.1% fewer estimated total tokens than traditional RAG, while its observed replay is 99.7% slower. Traditional RAG is fastest. There is no single composite winner.

06 / selective memory

Selective-memory wins and miss

Selective memory was the only highest-scoring approach on Q16, Q17, Q25. Its remaining miss is an event-provenance error on Q23: the answer cited nearby keyboard-coverage events instead of E081 and E086.

Interpretation. The result supports a bounded claim about this fictional 90-event dataset and this replay. It does not establish general superiority across models, datasets, or repeated trials.
